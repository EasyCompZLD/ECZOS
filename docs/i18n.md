# ECZOS internationalisation

## Language scope

ECZOS follows the 78 choices in Debian 13's `localechooser` 2.112 language
matrix, recorded in `config/supported-languages.tsv`. The `C` locale and English
use the English source text, leaving 76 translation catalogues. Locale variants
such as Brazilian Portuguese, Simplified and Traditional Chinese, Norwegian
Bokmaal and Nynorsk, and Northern Sami remain separate.

Support has three distinct states:

1. **Fallback** — untranslated text is safely shown in English.
2. **Complete catalogue** — every current source string has a translation.
3. **Reviewed** — layout, terminology, placeholders and actions were checked by
   a proficient speaker on the actual ECZOS interface.

ECZOS must never present an empty catalogue as a completed translation. Arabic,
Hebrew, Persian and Uyghur additionally require right-to-left layout tests. CJK
and Indic languages require font and text-overflow qualification.

ECZOS uses the desktop locale (`QLocale::system()`) and falls back to the
English source strings when a translation is unavailable. Qt Settings strings
are translated with Qt Linguist (`.ts` → `.qm`); QML uses `qsTr()` and the
native launcher loads the matching `eczos-system-settings_<locale>.qm` at
startup.

The first catalogues are Dutch, German and French. The complete first-boot OOBE
is available in those languages; ECZOS Settings is being converted page by
page while its UI is stabilised. New strings must use `QObject::tr()` in C++ or
`qsTr()` in QML; internal route IDs, package names and JSON keys must remain
language-neutral.

Translation catalogues are compiled during Debian package builds and installed
below `/usr/share/eczos/translations`. A package must not claim a language merely
because it loads `QTranslator`: its `.ts` source and packaged `.qm` file are both
required, and every catalogue must contain exactly the current source strings.

To add a language, add its `.ts` file to `native/CMakeLists.txt`, translate it
with Qt Linguist, and run the package smoke test. Additional Debian locales can
then be added in batches and reviewed by a native speaker before release.
