# ECZOS 0.1.1

ECZOS 0.1.1 is the first consolidated maintenance release after ECZOS 0.1.0.

Highlights:

- integrated ECZOS Settings with hardware, boot, sharing and support tools;
- improved ECZ Windows application detection, repair and executable override;
- improved classic-game, network-drive and optical-drive compatibility;
- refreshed ECZOS installer slideshow and first-run experience;
- package-owned Calamares configuration that cannot fall back to Debian
  branding after a settings-package update;
- updated recovery-media, diagnostics and software-update workflows.
