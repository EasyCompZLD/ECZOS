# eczos-platform-tools

This package provides a coherent Qt/QML ECZOS settings surface without replacing
KDE System Settings. One shared interface brings together native app discovery,
ECZ Windows, Gaming, devices, Kup backup, KDE Connect, migration, diagnostics,
recovery media and support. Python is used only as the invisible integration
layer; users do not see Python's default widgets or terminal windows.

The migration assistant defaults to a dry run, copies only known personal
folders and never overwrites existing destination files. The support report is
stored locally with private permissions and is never sent automatically.
