# eczos-branding

The first ECZOS Debian package. It owns only static branding files below
`/usr/share/eczos/branding` and deliberately has no maintainer scripts.

The `0.1.0~dev1` version is internal development metadata, not a public ECZOS
release number.

Asset provenance must be resolved before public distribution. See
`debian/copyright` and `docs/asset-provenance.md`.
