# eczos-desktop-defaults

This package provides one-time KDE Plasma defaults for new ECZOS user profiles
and user-invoked light/dark appearance controls.

The first-run action selects Debian's Breeze presentation and the blue primary
ECZOS wallpaper. Automatic, light and dark wallpaper modes remain available as
explicit user choices. Plasma's standard bottom panel is retained because it
already provides the intended familiar application-menu, taskbar and system-tray layout.
An XDG state marker prevents later logins from overwriting user choices.
